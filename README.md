# Energy Operations Platform

The Energy Operations Platform is a developing enterprise operations concept focused on energy-sector work management, operational analytics, production tracking, billing validation, asset utilization, and lifecycle visibility.

This repository began as an enterprise data analytics project and is being expanded into a broader systems architecture and prototype environment.

## Current Focus

- SQL Server data modeling
- operational workflow design
- work order, purchase order, and invoice lifecycle tracking
- asset/equipment analytics
- billing and revenue assurance concepts
- Power BI reporting
- future Blazor/API prototype development

## Technology Direction

- SQL Server / Azure SQL
- ASP.NET Core Web API
- Blazor
- Power BI
- Azure App Service
- Azure Blob Storage
- Microsoft Entra ID
  
## Data Policy
All data, entities, records, names, identifiers, transactions, billing items, contracts, invoices, work orders, vendors, employees, customers, regions, crews, and operational scenarios included in this project are entirely fictional and created solely for demonstration, development, and portfolio purposes. Any resemblance to actual persons, companies, customers, vendors, contracts, invoices, work orders, systems, or operational records is purely coincidental. No real customer data, employer data, vendor data, employee data, billing data, invoice data, contract data, or work order data is intentionally used or represented.
